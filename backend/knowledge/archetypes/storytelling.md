# Guided narrative

Establish context, show the change, explain its drivers, then state the action. Ask what conclusion the audience should reach and what comparison supports it. Use clear titles and annotations without inventing causal claims. Order visuals to support the narrative.

Use the shared 12-column grid and a single page. Choose only allowed catalog components and connect each high-priority question to a question_ref. Confirm metric units, aggregation and time grain before planning.
