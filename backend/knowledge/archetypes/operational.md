# Action and monitoring

Show current status, exceptions and the queue requiring action. Ask about thresholds, ownership, refresh cadence and escalation rules. Use filters, status KPIs and actionable tables; show the reporting period and freshness limitations.

Use the shared 12-column grid and a single page. Choose only allowed catalog components and connect each high-priority question to a question_ref. Confirm metric units, aggregation and time grain before planning.
